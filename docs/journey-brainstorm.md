> 格式约定（每一点 = 一个 `###` 块，机器可解析，别破坏结构）：
> - 标题行：`### <编号> <标题>`，编号 = 段字母+序号（如 `D3`）。加新点就续号；删点直接删块。

## 定义（已锁定，CONTEXT.md）

用户经**落地页**第一次接触产品起，到「宠物在云端活着、为我进化、它推的我会在」的信念成立（Day 7+ 仍主动回访）为止，全部有意图接触时刻的序列。
缺陷判定：**每个 hop 的承诺必须可兑现**，一切影响精致的落差都算路径缺陷。

## A 落地页 / 获客面

> 现状真空：无 landing / 登录页，第一跳是裸 302 到 Casdoor 表单。起点已锁为「第一次听说产品」。

### A1 首屏叙事装置
- 状态:
- 问题: 首屏用什么解释「这是什么」？
- 选项:
  - **功能文案** — 一句话+截图直球
  - **官宠实录** — 一只真宠物的今天（足迹/日记/一条真推送）
  - **世界观先声** — 博物图鉴腔调开场，产品后置

### A2 门口演示宠物
- 状态:
- 大票: yes
- 问题: 落地页能不能「逛」？匿名可看什么？
- 选项:
  - **平台官宠公开** — 匿名看它今天的状态/日记/推送流，注册是为了拥有自己的
  - **纯静态页** — 图文介绍，注册后才能见活物
- 阻塞: A3、A5

### A3 唯一 CTA 放哪
- 状态:
- 问题: 转化按钮的形态？
- 选项:
  - **注册直给** — 一个按钮，别分心
  - **软漏斗** — 「先看看街溜子们」→ 逛官宠 → 被说服才注册

### A4 分享的署名承诺
- 状态:
- 问题: 被手动转发的东西带不带来源？（不做裂变机制，但被转内容 = 落地页流量生死开关）
- 选项:
  - **自带署名** — 表情包下载图带出处水印 + 落地页链接
  - **不署名** — 干净图，传播即失联

### A5 世界观 vs 转化话术
- 状态:
- 问题: 维多利亚图鉴的腔调和一秒看懂的人话，谁让步、让到哪？
- 选项:
  - **腔调优先** — 筛选目标用户，宁劝退路人
  - **人话优先** — 世界观只活在皮肤里

## B 注册 hop

> 现状：OIDC 直跳 Casdoor 页，产品叙事零露出；字段 = 用户名+显示名+密码。

### B1 注册 UI 归属
- 状态:
- 问题: 「精致」标准下的头号违反：用户先看到别人的表单。谁出皮？
- 选项:
  - **自建注册页套皮** — CAS/OIDC 仍在后面，样式与叙事自持
  - **Casdoor 主题定制** — 改官方模板，成本低但戴着镣铐

### B2 注册时刻的承诺文案
- 状态:
- 问题: 按钮旁说什么，让用户知道注册的不是账号而是宠物？
- 选项:
  - **「注册 = 可以领养一只宠物」明示**
  - **字段再减** — 显示名当唯一必填试试

## C 领养仪式

> 4 步（起名→性格→口头禅→兴趣）已实现，LLM 3 候选+换批限 3 次。仪式内部已 grill 过，这里只问边界。

### C1 仪式中断恢复
- 状态:
- 问题: 第 3 步关页面回来是什么？现状：整个仪式重跑，已填全丢。
- 选项:
  - **服务端草稿** — 恢复到中断步
  - **重跑可接受** — 4 步而已（精致标准下大概率不行）

### C2 名字候选的品质兜底
- 状态:
- 问题: 3 批 9 个名字全不满意，然后呢？
- 选项:
  - **自由输入** — 校验要配得上「它会自己说出口」
  - **强制三选一** — 产品替你审美（冒犯风险）

### C3 兴趣冷选的质量
- 状态:
- 问题: 第 4 步选的兴趣直接决定首推。乱选/敷衍选 = 首推必烂。要不要更强示范？
- 选项:
  - **后果预告** — 「它会从这里开始为你游荡」+例子
  - **保持轻** — 选错也是进化素材

### C4 自我介绍的剧本
- 状态:
- 问题: PetIntro 固定 5 行打字机——它是「活物感」的第一次证明，当品牌资产打磨吗？
- 选项:
  - **性格分剧本** — 四种性格四套开场
  - **一套精品** — 文案极致即可

## D 首推 / 激活期

> 旅程最大裂缝：新宠物首个 tick 就能游荡，但 PushGate 阈值 0.5 意味着可能连几天零动静——整个信念押在首推上。

### D1 首推有没有保证
- 状态:
- 大票: yes
- 问题: 产品承诺「它会主动推你感兴趣的东西」，第一次兑现要不要兜底？
- 选项:
  - **强制过闸** — 领养后首轮游荡必出一推（牺牲「只学不推」的克制）
  - **诚实等待** — 改口「首推可能要等几天」，配合 D2
- 阻塞: D2、D3、D4、D5

### D2 等待期看什么
- 状态:
- 大票: yes
- 问题: 领养完成 → 首推落地之间，主页空态怎么把「它还在长大」变成可见过程？
- 选项:
  - **过程可视化** — 游荡进行指示 / 第一条足迹 / 成长进度
  - **无事可做** — 那就是设计失败

### D3 首推内容挑选
- 状态:
- 问题: 第一推推什么算赢？平庸一条信念直接崩。
- 选项:
  - **专门选材策略** — 最高置信话题+配图加持
  - **与日常同权** — 让进化自然说话

### D4 Web Push 订阅时机
- 状态:
- 问题: 现状藏在设置页。浏览器权限不可逆，问错一次就没了；iOS 还需先加桌面。
- 选项:
  - **领养完成页求** — 情绪峰值，但有拒授权风险
  - **首推落地后引导** — 已尝到甜头，转化慢一拍

### D5 首推落地的仪式
- 状态:
- 问题: 第一推和普通推送长得一样吗？
- 选项:
  - **专属完成态** — 它是「领养成功」的真正落锤
  - **不打扰** — 安静地推

## E 反馈回路

> 👍/👎/顶话题已实现（REST POST→worker 归因），但入口藏在 /history，反馈完无下文。

### E1 首页身份之争
- 状态:
- 大票: yes
- 问题: 主页 = 图鉴（现状），推送流+反馈在 /history——习惯回路的入口不是首页。
- 选项:
  - **主页=今天** — 推送+宠物状态置顶，图鉴退二级
  - **维持图鉴** — 氛围优先，接受动线绕
- 阻塞: E2、F6

### E2 反馈的回声
- 状态:
- 问题: 👍之后用户**看见**什么？现状按钮变色即终。没有可见回声，「它收到并在变」全靠脑补。
- 选项:
  - **即时回声** — 宠物当场道谢/记小本本动画
  - **延迟回声** — 之后推送/日记里提起「因为你点了赞」
  - **两者**

### E3 顶话题的仪式化
- 状态:
- 问题: 免费 1 次/月的强稀缺动作，现在是普通按钮。稀缺值得重量吗？
- 选项:
  - **仪式化** — 选话题→宠物确认→预告「我这就去找」
  - **保持轻** — 仪式变摩擦

## F 日常 / 习惯回路（Day 2–7）

> 日记/梦境/拍拍/作息/图鉴功能全部有实现或半成品，但「凭什么每天回来」没人系统地想过。

### F1 日记的日常钩子
- 状态:
- 问题: 每天几点推、什么形态、怎么让人非看不可？
- 选项:
  - **摘要+链接 vs 全文推送**
  - **连载悬念** — 日记叙事埋连续性（今天提到明天要去看的东西）

### F2 梦境的发现仪式
- 状态:
- 问题: 夜间首次访问看到睡眠+梦境的完整体验？
- 选项:
  - **夜间限定** — 访问才可见，制造生物钟
  - **醒时摘句** — 白天给一条「它昨晚梦到 X」（低打扰高活物感）

### F3 拍拍的兑现回路
- 状态:
- 问题: 现状纯前端假动画（违反承诺兑现标准）。接真后反馈到什么程度？
- 选项:
  - **轻** — 只改当日 mood，动画即终
  - **有记忆** — 宠物在之后日记/推送里提起「你今天拍我了」

### F4 醒来时刻
- 状态:
- 问题: 「它睡了/它醒了」能变成回访钩子吗？
- 选项:
  - **醒来留物** — 醒后第一件事给主人留点什么
  - **不打扰** — 作息只是背景设定

### F5 表情包首现节奏
- 状态:
- 问题: 旅程哪一步第一次出现、以什么身份？
- 选项:
  - **推送附件** — 首推或早期推送带图
  - **图鉴惊喜** — 回访时偶然发现存货

### F6 无事可做时看什么
- 状态:
- 问题: 没推送没日记的普通一天，主页提供什么微互动？留存产品必须回答「今天没有新东西」时的去处。
- 选项:
  - **翻足迹/看兴趣图谱长大/看它在干嘛**
  - **轻互动** — 拍拍/说话

## G 付费 hop（接触时刻已入册）

> 三档边界已锁定不重开；入册的是「限额撞到人脸上」的设计。

### G1 限额接触的设计语
- 状态:
- 大票: yes
- 问题: 429 / 置灰时刻谁开口？性格化 upsell 是这产品独有的可能性，也独有翻车风险。

  - **系统横幅** — 干净直接，不拿感情做买卖
  - **分场景** — 轻限额宠物口吻，硬墙系统语

### G2 「核心免费」的传达
- 状态:
- 问题: 升级提示必须同时说清「自进化永远不卡你」——怎么摆措辞，不让人误以为免费版是残废。
- 选项:
  - **对照表** — 卡的是操控频率不是灵魂
  - **一句话注脚**

### G3 BYOK 的发现路径
- 状态:
- 问题: 重用户从哪知道有自带 key 档？（他们永远不会主动点开套餐页）
- 选项:
  - **用量撞墙时提示** — 「你的量走 BYOK 更划算」
  - **设置页常驻入口**
