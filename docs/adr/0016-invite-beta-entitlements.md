# 0016 免费邀请内测与有效权益

日期：2026-10-04
状态：已接受（用户确认「邀请制，保留正常交互」）

## 决策

当前阶段仅邀请制进入，所有新老受邀账号统一享有原第二档 Pro 权益，不展示收费套餐、购买或升级入口。领养、反馈、兴趣方向引导、推送时段设置及配额内形象生成保持开放。

权益由 `packages/control-plane/src/plan/entitlements.ts` 统一计算，数值与 API 契约归 `@cyber-stray/shared/plan`。`CP_PRODUCT_MODE` 缺省为 `invite_beta`，有效 plan 为 Pro，与旧数据库存储的 plan 无关，因此无需迁移或批量修改已有账户。上限为每日 20 次推送、每日一次兴趣引导；平台成本预算、生成额度等护栏继续有效。

BYOK 作为可选凭据保留，不作为新收费档，也不承诺无限用量。已有绑定无需清除。

## 未来付费边界

保留持久化 plan、`ProductMode`、权益解析与 billing 状态。未来支付提供方只在这些边界接入，不让页面分别解释存储 plan。当前 `paid` 模式启动明确报错，避免误开未实现的购买能力；内测账户不会自动转为收费订阅。

若未来发布付费模式，需另行确定定价、现有内测用户待遇、支付和退款流程，并实现服务端订阅凭证校验。上述均不属于本次改动。

## 交互与网络边界

Web 仍通过 CP API 和 SSE 消费数据；「只读」指不直接写 agent 文件，不限制用户通过显式 CP 端点领养、反馈、修改设置。

SaaS worker 的外部浏览器 CLI 暂停开放：当前 CLI 无法保证每次连接都遵守 DNS 验证后的 IP 约束。搜索与 `read_page` 保留，网页、用户渠道和 Web Push 目标通过共享出站守卫校验公网地址、重定向、响应体大小和超时。重新开放 SaaS 浏览器前必须具备可靠的网络隔离。

## 验证

回归覆盖旧 free/byok 账户的有效 Pro 权益、邀请登录、反馈与推送时间、形象生成权限、日预算和调度限制。数据库验证只使用临时测试库，不迁移现有环境。
