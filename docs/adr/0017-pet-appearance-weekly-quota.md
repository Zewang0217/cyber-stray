# 外观生成统一九态、七天额度与休息交互

2026-10-08，用户确认 admin 黑猫的画质，要求检查状态一致性、正常领养采用同档方案，并将改造屋限制为一周一次、admin 不限次。

首次领养原先生成 64px 多帧 sheet，改造屋生成 256px 九态单帧。新领养使用 adopt 初始策略：以可选上传图生成概念锚点，自动确认后转入现有 quad/nine/per 九态管线，全部状态通过质检才交付。管理员不拥有专属画质。已有 sheet/strip 任务与素材继续兼容。新策略只扩展既有 TEXT 字段的 TypeScript 枚举，无 DDL 或迁移。
