# Spike:单图多状态生图管线(issue #89)

> 目的:实测"单图多状态"两条路径(九宫格 3x3 vs 四宫格 2x2),用真实生图 API 与真实切分脚本出四维数据,落定素材契约与回退条件。
> 日期:2026-08-20。API:qwen-image(DashScope async)。参考 ADR-0001(图文分离/参考图锁角色/单图多状态)。

## 0. 结论速览

| 维度 | 九宫格 3x3(A) | 四宫格 2x2 × 3(B) | 胜者 |
|---|---|---|---|
| 每格源分辨率 | ~245px(1:1 到 256 画布) | ~470px(2x 超采样) | **B** |
| 切分稳定性 | 行/列检测全中,0 兜底 | 空格/暗带触发均分兜底,输出仍正确 | **A** |
| 角色一致性(HSV 直方图) | 0.77(无参考) / 0.44(参考) | 0.39–0.44 | **A**(均弱) |
| 成本 | 2 calls → 0.22 call/状态 | 3 calls → 0.33 call/状态 | **A** |
| 失败粒度 | 1 张坏 → 9 状态全重来 | 1 张坏 → 只重来 3 状态 | **B** |
| 空位指令顺从 | 不适用 | 2/3 顺从(B3 画满 4 格) | — |

**推荐:四宫格(2x2 × 3 张)为主路径**——每格 2 倍源分辨率(角色细节更足)、失败重试粒度小(单张 3 状态),切分脚本已支持空格跳过。九宫格作为低成本备选(分辨率要求不高时 0.22 call/状态更省)。**回退到现有逐状态生成**(pet-sheet 流程)的条件见 §4。

> 关键 caveat:本轮参考图用的是**现有素材首帧黑底合成图**(alpha → RGB 变黑底),qwen-image 图生图参考模式**未显著锁住角色**(内部一致性反而低于纯提示词 A1:0.44 vs 0.77)。参考图锁角色需用干净的透明底/白底概念图重测,见 §5。

## 1. 实验设置

### 1.1 API 与成本控制
- 端点:`POST /api/v1/services/aigc/text2image/image-synthesis`,**必须 `X-DashScope-Async: enable`**(本账号不支持同步调用,同步直接 `AccessDenied`)。
- 轮询:`GET /api/v1/tasks/{task_id}`,SUCCEEDED 后取 `results[0].url` 下载。
- 参数:`size=1024*1024, n=1`;参考图走 `input.image`(base64,**≤61440 字符**——256px PNG 超限,需压成 JPEG)。
- 每路径 ≤3 次生成:路径 A 实耗 2 次,路径 B 实耗 3 次。生成成功率 **7/7 = 100%**(含 2 次预探测)。
- 环境:`DASHSCOPE_API_KEY` 在 shell env 中可用(不在 `.env` 文件里)。

### 1.2 提示词设计
- 角色描述:圆润 chibi 鲸鱼女孩,奶油米色身体、柔和粉彩、大眼睛、小鳍小尾,kawaii 游戏精灵风格,绿幕底(#00FF00)。
- **A 九宫格**:一张 3x3,9 格各 1 状态(idle/walk/joy/eat/sleep/think/celebrate/grumpy/welcome),行优先,统一格子大小,角色不出格。
- **B 四宫格**:一张 2x2,3 个状态 + 右下角**空 1 格**(纯绿),共 3 张覆盖 9 状态。
- 参考图:A2/B1-B3 传 `input.image` = 现有素材 idle 帧 0(JPEG 压缩)。

### 1.3 切分脚本
`packages/web/scripts/pet-sheet.py` 新增 cells 模式(本次 spike 扩展):
- `--grid --cells --states <9 状态>` → 3x3 每格 1 状态 1 帧
- `--grid --cells --cols 2 --states <3 状态>` → 2x2,空格跳过
- 双掩码:网格检测用 `detection_mask`(绿幕 ∪ 白线),帧提取用纯绿幕 `chroma_key_green`(避免吃掉角色身上白色)
- 行/列带检测失败自动均分兜底并打 `[warn]`(切分稳定性即来自此统计)
- 原 strip 模式(3 状态 × 3 帧帧条)完全兼容,合成测试 4/4 通过

## 2. 四维数据

### 2.1 每格清晰度 / 可用分辨率

| 实验 | 角色源尺寸(px) | 源格大小(px) | 归一化后内容% | Laplacian 锐度 |
|---|---|---|---|---|
| A1 九宫格·无参考 | ~245×239 | ~341 | 41.3% | 1918 |
| A2 九宫格·参考 | ~223×208 | ~341 | 40.2% | 2515 |
| B1 四宫格 | ~470×468 | ~512 | 31.5% | 3775 |
| B2 四宫格 | ~470×468 | ~512 | 49.6% | 1982 |
| B3 四宫格 | ~470×468 | ~512 | 34.6% | 2560 |

- 3x3 每格 341px,角色占满格(245px 源)→ 256 画布 1:1,无放大,够用但无余量。
- 2x2 每格 512px,角色 470px 源 → 256 画布 **2x 超采样**,细节密度更高(B1 锐度 3775 vs A1 1918)。
- 结论:**四宫格分辨率显著胜出**;九宫格内容占比更高(角色更大更饱满)。

### 2.2 切分稳定性

| 实验 | 行检测 | 列检测 | 兜底 | 输出正确性 |
|---|---|---|---|---|
| A1/A2 九宫格 | 3/3 ✓ | 每行 3/3 ✓ | 0 次 | 9/9 状态 ✓ |
| B1/B2 四宫格 | 2/2 ✓ | 底行 1/2(空格)→ 均分 | 1 次/张 | 3/3 ✓,空格跳过 ✓ |
| B3 四宫格 | 1/2(暗带合并行)→ 均分 | 均分 | 3 次 | 3/3 ✓(但 3 状态几乎相同) |

- 九宫格检测全中,零兜底。
- 2x2 的**空格位破坏列簇检测**(底行只有 1 个内容簇),触发均分兜底;输出仍正确,因为均分恰好命中模型画的等分格线。
- **空位指令顺从不稳**:B1/B2 顺从(右下 0.2%/0.0% 前景),**B3 画满 4 格**(右下 21.1%)且中间有暗色分隔带 → 全兜底。切分脚本兜底逻辑保证了不崩,但语义上 B3 这轮是次品(见 2.3)。
- 状态错位/漏切:九宫格 0,四宫格 0(兜底兜住了);真正的风险是"模型不按 2x2 画"(B3)。

### 2.3 角色一致性(HSV 24×24 直方图相关)

| 实验 | 内部两两均值 | 漂移状态(与 idle 相关 <0.25) | 参考图相关 |
|---|---|---|---|
| A1 九宫格·无参考 | **0.767** | sleep(闭眼深色,可能合理) | 0.02 |
| A2 九宫格·参考 | 0.441 | **think/celebrate/grumpy/welcome 4/9** | 0.01 |
| B1 四宫格 | 0.39 | **joy 画成红棕色**(源格 60% 红调) | 0.02 |
| B2 四宫格 | 0.44 | think(小 bbox) | 0.01 |
| B3 四宫格 | 0.98(伪) | —(3 状态几乎同一姿势同一色) | 0.01 |

- **纯提示词 A1 一致性最好(0.77)**:除 sleep(闭眼深色)外 8/9 状态同色同款。
- **参考图没有锁住角色**:A2 反而 4/9 漂移,B1 把 joy 画成红棕。与旧素材(低饱和米色)的直方图相关只有 0.01–0.02——生成角色整体比旧素材饱和度高。
- 跨图同状态:闲置/走路跨 A1/A2 相关 0.97–0.98(角色本身稳定),但 B1 joy 异常 → 单状态漂移无法靠提示词兜底。
- **B3 一致性 0.98 是假象**:3 状态全部画成几乎相同的姿势 → 状态区分失败,这是比颜色漂移更严重的问题。

### 2.4 成本与失败率

| 路径 | API 调用 | 调用/状态 | 生成失败 | 功能性失败 |
|---|---|---|---|---|
| A 九宫格 | 2 | 0.22 | 0/2 | A2 4/9 状态色漂 |
| B 四宫格 | 3 | 0.33 | 0/3 | B1 joy 红化;B3 状态未区分 + 画满 4 格 |
| 回退:逐状态 | 9(每状态 1 次) | 1.0 | — | 一致性最强,成本最高 |

- 生成层失败率 **0/7**。真正的失败在语义层:状态漂移/未区分(提示词 + 参考图问题,非管线问题)。
- 九宫格 2 次调用覆盖 9 状态;四宫格 3 次;逐状态 9 次。四宫格比逐状态省 **3x** 成本,九宫格省 **4.5x**。

## 4. 推荐方案与回退条件

### 推荐:四宫格(2x2 × 3 张)为主路径
1. **分辨率**:每格 512px 源,角色 ~470px → 256 画布 2x 超采样,细节与抗锯齿最好。
2. **失败粒度**:单张 3 状态,坏一张只重生成 3 状态(1 次调用),九宫格坏一张要重来 9 状态。
3. **切分已支持**:空格跳过 + 均分兜底,输出结构稳定。
4. 成本 0.33 call/状态,仍比逐状态省 3x。

### 回退条件(任一触发 → 回退)
1. **qwen-vl 语义质检**(ADR-0001 两层质检):状态未区分率 > 1/3(B3 现象)或状态漂移率 > 1/3 → 回退**九宫格**;若九宫格仍漂移 → 回退**逐状态生成**(现有 pet-sheet 流程,每状态 1 次调用)。
2. **切分失败率 > 1/3**:行/列检测连续失败且均分兜底产物角色被切断(内容占比 <20%)→ 回退。
3. **空位指令顺从率 < 2/3**:连续两轮模型把 2x2 画满 → 放弃 2x2 布局,改九宫格或逐状态。

### 九宫格的定位
低分辨率余量场景(纯贴纸/小图标)下,九宫格 0.22 call/状态最省,且本轮 A1 内部一致性 0.77 最佳——**在参考图锁角色成熟之前,九宫格+纯提示词反而是最稳的**。两条路径都保留在脚本里,按需求切换。

## 5. 素材契约建议(供 #94/#95,本次不改消费方)

1. **帧格式**:每状态 1 帧静态,256×256 透明 PNG(`<state>.png`),沿用现 manifest 结构 `{state: {frames: 1, frame: 256}}`。
2. **manifest**:`meta.json` 已自动生成;建议每状态加 `dur`(程序微动画周期)与 `label`(无障碍),字段对齐 `lib/pet-sprite.ts` 现有 `PetStateSpec`(frames 改 1,后续消费方 #94/#95 再动)。
3. **程序微动画参数**(替代多帧):idle 呼吸(y 缩放 1±0.03,周期 1.6s)、walk 水平位移 + 脚部摆动、joy 弹跳、celebrate 缩放弹跳、sleep 慢呼吸、grumpy 轻微倾斜;参数存 manifest,播放器 JS 帧驱动。
4. **参考图锁角色(重要)**:本轮黑底参考图未生效 → **必须用透明底/白底概念图重测**;参考图与生成角色风格尽量一致(旧素材低饱和,模型会自行提饱和)。若参考图多次仍不锁色,降级为"提示词锁角色"(A1 效果反而最好)。
5. **绿幕与格线**:提示词固定 `#00FF00` 纯绿底;模型可能自加白线分隔(2x2 常见),脚本双掩码已兼容。不要在角色上画白色大色块(会被白线掩码误判,已用提取/检测分离规避)。
6. **质检**:结构层(帧数/透明底/内容占比 ≥20%)脚本内;语义层(qwen-vl:状态正确/角色一致/无文字水印)生成后逐状态,失败单状态重试。
