# 街角美术预览 v1

生成方式：内置 imagegen，2026-10-08。生图负责街巷和透明花盆，代码负责宠物、窗灯、月相、水沟盖和每日布置；没有引入外部素材库或新的前端依赖。

- `night.webp`：夜间书店、咖啡店与中间巷子，768×512。
- `day.webp`：同一街区的日景，768×512。
- `planter.webp`：从同风格参考生成的独立透明花盆，保留 alpha，最大边 64px。

背景按 3:2 同坐标画布摆放，窄屏居中取景。窗灯、月亮和井盖热区跟随这张画布，而不是单独根据屏幕宽度定位。仅使用 nearest 导出像素网格及无损 WebP，未做有损模糊压缩。

原始生图和完整提示词记录在交付目录 `artifacts/street-corner-20261008/`。场景插画保留模型生成的丰富色阶，界面与交互控件沿用现有色板 token；不要将本方案描述为已经严格量化到十四色。用户确认后的例外范围已记录在 `docs/design-v3/DESIGN.md`。

2026-10-08 用户已确认本版场景美术。咖啡窗口新增小杯热气，夜间咖啡灯箱偶发暗闪；使用代码叠层，无需重新生图，也不新增宠物动作。两类动效共用 16 秒周期、错开播放，暂停于页面不可见时；减少动态效果时停用装饰动效。原两名路人减为一名，给环境动效留出预算。

用户已确认本版美术与动效，按 develop → main 的 PR 流程发布。宠物生成与素材契约未改动；静态美术由 web 镜像携带。
