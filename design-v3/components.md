# components.md · 组件规范

> 行为基座：Radix 无头原语 / vaul / sonner（见 stack.md），可见面 100% 手写像素皮肤。
> 命名即文件名：`packages/web/src/components/<Name>.tsx`。

## PixelStage 街区舞台（核心组件）

- **用途**：宠物活体的家，"宠物活着可见"硬约束的载体。
- **视觉**（#208 实现口径修订）：一整块游戏屏——夜空（`--sky` + 2px 星点 + 5×5 像素月亮可点击换八相）、四栋楼剪影（远景 `--bld-far` / 近景 `--bld-near`，窗 = 8×10 `--window` 色块，seed 伪随机 55% 基态点亮 + 点按切换亮/灭，基态不随点按漂移）、路面 `--street` + 路缘水沟盖（点按冒一次性蒸汽）、第三栋楼顶霓虹招牌 `OPEN`（静态 opacity hover 亮起）。
- **宠物**：像素猫 sprite（站立idle 4帧/行走 4帧/拍拍 2帧/扑向 2帧），站在路缘线上；头顶名牌贴纸（纸片 4px 描边 + 实色落影）。
- **交互**：点击猫 = 拍拍（pat 帧 + 爱心像素粒子 + 心情条 +1）；点击「让它去溜达」= 猫走出屏幕 → 日志推进 → 明信片寄回（完整编排见 motion.md §5）。
- **街角变体（#219）**：店铺街 / 住宅巷 / 公园口 三套按自然日轮换（dayNumber % 3，挂载后求值防 hydration 错位）。氛围件全静态色板内取色：路灯暖光锥（--window 三层阶梯透明）、地面反光（低透明色条）、电线（curb 折线）、天台水箱/天线、空调外机、停靠车辆、公园口像素树+长椅。店铺门面与 OPEN 霓虹仅店铺街变体。
- **可交互装饰（#208）**：点窗灯亮/灭（基态 seed 决定）、点月亮循环八相（aria 报相位）、点路缘水沟盖冒一次性蒸汽（reduced-motion 停帧）、霓虹招牌 hover 亮起（静态 opacity 态）。全部方角像素语法 + aria 可达；动效遵守 motion.md §5 预算（新增动画仅蒸汽一处一次性 transform/opacity）。
- **尺寸**：桌面 480×280（1x 网格 96×56 像素）；移动端满宽，保持 16:9 内比例。

## HUD 状态面板

- 一条 `--panel` 面板横栏：`LV.7 游荡者`（Press Start 2P）+ 三条**分段墨条**（10 格，2px 墨描边）+ 一枚心情枚举标签（#217/ADR-0013 §4 修订）：**精力 / 无聊 / 脾气 = 后端原始值零换算**（精力高=好，<20 告警闪；无聊/脾气 >80 告警闪，告警色 `--bad`）；心情 = 枚举原文 curious/playful/excited/lazy/grumpy/emo 徽章呈现，不做分数换算；state 缺失 → 墨条显 `? ? ?` 未知态、心情显 `--`，禁伪装健康兜底。「饥饿」字样与 100−energy 映射已废（演出层的饿脸保留）。
- 数值变化 = 墨条逐格跳变（每格 2 游戏帧）；饥饿 > 80：该条以 steps(1) 闪烁 + 猫的 idle 切"饿"层。
- 状态文案用像素字体短串：`饱` / `想出门` / `得劲`。

## MailCard 明信片（推送）

- **视觉**：`--paper` 纸底 4px `--ink` 描边 + `6px 6px 0 #000` 实色落影；右上角 16×16 **像素邮票**（4 款轮换：猫爪/邮票齿孔/街区/月亮）；左上 mono 竖排 `DAY 12 · 22:38`；未读左上角 `NEW!` 黄徽章 steps 闪烁。
- **内容**（#205 修订）：卡片只显标题 = 像素字体（≤ 18 字，点卡片开详情模态）；摘要/完整正文只在详情模态（Noto Sans SC 长文）；来源 = 像素小方签 `TAVILY`/`DDG`。
- **操作行**：像素拇指（▲绿/▼红）+ `置顶话题`（`--hi` 黄底方签）+ `看原文`（`--act` 蓝底按钮）。
- **堆叠**：最多 5 张，新卡把旧卡下推（auto-animate）；街角只留最新 1 张 + 「墙上还有 N 张 →」，历史进「墙上」菜单页（2026-09-06 重铸映射定，vaul 抽屉让位给墙上 Tab）。

## DialogBox 对话框（宠物说话）

- 游戏AV语法：纸底 + 4px 墨描边 + 底部三角尾巴 + 左上 `<年糕>` 名签（黄底）；文字 = Fusion Pixel/DotGothic16 逐字打印（每字 2 游戏帧）；右下角 ▼ 闪烁 = 还有话。
- 出现时机：状态变化、拍拍、新邮件、随机 20-40s。

## WanderLog 游荡日志

- `--panel` 底 + 2px `--curb` 框；VT323 18px，`--star` 白字；新行从底部推入（无过渡，直接换帧 + 光标 `■` 闪烁）。
- 语法：`[22:38] 无聊72 → 出门 → TAVILY 独立游戏新闻 → 抓到3条 → 进食`。
- 一屏 4 行，滚出即逝（游戏 log 不留历史，历史在抽屉）。

## AppTabBar 游戏菜单条

- 底部通栏 `--panel`，2px `--curb` 上边框；4 个菜单项（像素图标 + 像素字体短标签）：`街角` `墙上` `图鉴` `设置`。
- 激活 = `--act` 蓝底白字 + 底部 2px `--hi` 黄线；未激活 = panel 色字。
- 桌面端 = 底部居中悬浮（demo 验收基准）；移动端底部通栏固定。

## PixelToast 通知（sonner 主题化）

- 游戏对话框样式的纸片从顶部落下（无缓动，12 帧到位），4s 后"啪"消失；宠物语气文案用对话字体。

## AdoptSheet 领养流程（Onboarding）

- 全屏 = 掌机开机画面：`STRAY-BOY` 铭牌 + `▶ NEW GAME`（Press Start 2P 闪烁）→ 领养登记：起名（像素字体输入框）→ 选初始兴趣（像素贴纸多选）→ 猫从屏幕右侧走进来坐下（walk 帧首次亮相）→ `开始游荡`。
- 唯一 confetti 时刻：确认领养（像素方块纸屑，`shapes:['square']`）。

## InterestAtlas 兴趣图鉴（pixel dex）

- 竖向轨道：每个兴趣 = 一格图鉴条目（像素编号 `No.003` + 名签 + 10 格关注度墨条 + `进化自 → No.001`）；新进化 = 条目翻转亮起（steps）+ NEW 徽章。
- 自绘 SVG/DOM，禁图表库。

## EmptyState / Loading

- EmptyState：对话框语法——`<年糕> 墙上还空着，等我溜达一圈。`
- Loading：猫形像素剪影原地小碎步（2 帧），禁 spinner。

## 通用规格

| 项 | 规格 |
|---|---|
| 触控目标 | ≥ 44px（掌机按钮本来就大）|
| 图标 | 全部像素画（box-shadow / crispEdges SVG，24×24 网格），随主题换色 |
| 焦点环 | `outline: 3px solid var(--act); outline-offset: 2px`（方角）|
| 骨架屏 | 像素砖块占位（2 帧明暗）|
| 文案 | 游戏腔：界面 = 掌机旁白（冷静短句）；宠物 = 游戏角色（活泼）|
