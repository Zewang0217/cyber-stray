# DESIGN.md ·「像素街区」世界宪法 v0.1

> Cyber Stray 的唯一主视觉世界。整个 PWA 是一台叫 **STRAY-BOY** 的掌机；屏幕里是一座微缩像素夜城，一只街溜子在楼宇间游荡，把找到的货寄成明信片回来。
> 供 AI 编码代理与人类开发者共同遵守。

---

## 1. 一句话与世界设定

**一台掌机，一座夜城，一只自己会动的猫。**

- 屏幕 = 像素夜城街区（宠物活动的地方，永远可见）
- HUD = 宠物状态（精力/无聊/脾气 + 心情标签/等级），像游戏一样常驻（#217：后端原始值零换算，「饥饿=100−精力」映射已废）
- 墙上/邮箱 = 明信片（推送内容从城里寄回来）
- 日志 = 游荡记录（游戏 log）
- 图鉴 = 兴趣进化（pixel dex）

关键：这不是养成游戏。猫自己进食自己找乐子，用户是**持机人**，只观察、回应、拍拍。

## 3. 像素字体纪律（本项目最难的一条，必须执行）

| 角色 | 字体 | 尺寸纪律 |
|---|---|---|
| Display/按钮/HUD（英文·数字）| **Press Start 2P** | 12/16/24px 整数倍；< 12px 禁用 |
| 中文短标签/标题 | **Fusion Pixel 12px**（生产自托管；demo 用 DotGothic16 + Noto 回退）| 只用于 ≤ 20 字的短串；12px 的整数倍缩放 |
| 日志/数字滚动 | **VT323** | 20px+ |
| 长内容正文 | **Noto Sans SC** | 14-15px，行高 1.7——**明信片摘要和长文必须用它**，像素字体排长文是可读性灾难 |

- 回退栈写法：`font-family:"Press Start 2P","Fusion Pixel 12px Monospaced","Noto Sans SC",monospace`——缺字自动逐字回退，这合法且必要。
- `image-rendering: pixelated` 只加在像素图/SVG 上，**不加在文字上**。

## 4. 六种签名手法（全站签名，必须规则化）

**1. 一切直角**：`border-radius: 0`（全局强制，含图片、头像、按钮）。

**2. 实色偏移阴影**（NES 立体感的全部秘密，禁 blur）：
```css
box-shadow: inset -4px -4px 0 rgba(0,0,0,.35),   /* 右下暗边 */
            6px 6px 0 #000;                       /* 实色落影 */
```

**3. 两帧法则**：一切动画 `steps(2)` 或 `steps(1)` 离散切换（呼吸、闪烁、摇摆、行走），时长用游戏帧（见 motion.md）。缓动曲线只有 `linear` 与 `steps`。

**4. 分段计量条**：精力/无聊/脾气一律 10 格分段墨条（2px 墨描边 + 色块），禁止连续进度条；state 缺失显未知态（---）不伪装健康（#217/ADR-0013 §4）。

**5. 像素图标**：图标 = 像素画（box-shadow 或 crispEdges SVG），或 NES.css 风格；**禁止平滑线性图标（lucide 也不行）**混入 UI 层。

**6. 对话框尾巴**：宠物说话 = 纸底对话框 + 底部三角尾巴 + `<名字>` 标签，游戏 AV 语法。

## 5. 掌机框架（页面结构隐喻）

页面 = 掌机面板：
- 顶栏：`STRAY-BOY` 型号铭牌 + 电源灯（呼吸绿点）+ DAY/N 时钟
- 主屏：街区场景（游戏层）
- 面板区：HUD / 明信片 / 日志（UI 层）
- 底部：游戏菜单条（TabBar）
面板与屏幕之间用 `--curb` 2px 分隔，屏幕内元素禁止溢出到面板上。

## 6. 明信片（推送）规范摘要

纸底 4px 墨描边 + 实色落影；右上角**像素邮票**（16×16 像素画，随机取 4 款）；未读 = 左上角闪烁 `NEW!` 黄徽章（steps 闪烁 1s）；标题 = 像素字体短串（≤ 18 字），摘要 = Noto Sans SC；左上 mono 竖排 `DAY 12 · 22:38`；操作行 = 像素拇指按钮。完整规格见 components.md。

## 8. 禁令清单（违反任何一条 = 不合格）

1. ❌ 渐变、圆角、模糊阴影、backdrop-blur（`border-radius:0` 全局强制）
2. ❌ 平滑缓动曲线（ease/cubic-bezier 弹性）——动画只有 `linear` 和 `steps`
3. ❌ 平滑线性图标（lucide 等描边图标库）出现在 UI 层——只用像素图标
4. ❌ 像素字体排长文（>20 字的正文一律 Noto Sans SC）
5. ❌ 色板 14 色之外发明新色；霓虹粉一屏超过 1 处
6. ❌ emoji 当图标（像素图标或字符 ▲▼●■）
7. ❌ 连续进度条（一律分段墨条）
8. ❌ < 12px 的像素字体
9. ❌ 图像 `image-rendering` 缺省（所有像素图必须 pixelated）
